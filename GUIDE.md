# 🚀 Гайд по запуску Survey App

## Для начинающих разработчиков

### Что делает этот проект?
Это веб-приложение для создания и прохождения опросов. Пользователи могут:
- Регистрироваться и входить в систему
- Создавать свои опросы
- Отвечать на опросы других
- Просматривать результаты

### Архитектура
- **Frontend**: React + Vite (современный интерфейс)
- **Backend**: Node.js + Express (серверная логика)
- **База данных**: MongoDB (хранение данных)

## Шаг 1: Подготовка
Убедитесь, что у вас установлены:
- Node.js (версия 14 или выше)
- MongoDB (база данных)

## Шаг 2: Клонирование и установка
```bash
# Скачайте проект
# Перейдите в папку проекта

# Быстрый запуск (все автоматически)
./start.sh

# Или ручной запуск:
cd backend && npm install
cd .. && npm install
```

## Шаг 3: Запуск
```bash
# В одном терминале - backend
cd backend
npm run dev

# В другом терминале - frontend
npm run dev
```

## Шаг 4: Использование
1. Откройте браузер: http://localhost:5173
2. Зарегистрируйтесь или войдите
3. Создайте опрос или пройдите существующий

## Распространенные проблемы

### "Cannot find module"
```bash
cd backend
npm install
```

### "Port already in use"
Измените порт в `backend/.env`:
```
PORT=5002
```

### "MongoDB connection error"
```bash
brew services start mongodb-community
```

## Следующие шаги обучения
1. Изучите код в папке `src/` (frontend)
2. Посмотрите `backend/controllers/` (backend логика)
3. Попробуйте изменить текст или добавить новую функцию
4. Изучите документацию React и Express
